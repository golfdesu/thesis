- [[CNN_LSTM_Transformer|CNN-LSTM-Transformer]] - 1D-CNN + LSTM + Multi-Head Self-Attention Transformer for multi-step 24h/48h fast-charging load forecast.

- [[QR_LSTM_Attention|Quantile Regression LSTM-Attention]] - LSTM Encoder-Decoder with Attention and Pinball Loss quantile estimation.
- [[MSSTGAN|Multi-Scale Spatial-Temporal Graph Attention Network (MSSTGAN)]] - Pyramid Split Attention + Graph Attention for city-level station network forecasting.
- [[ResMMoT_Informer|ResMMoT-Informer Architecture]] - Multiscale TCN sparse MoE routing + Informer ProbSparse self-attention.
- [[Transformer_BiLSTM|Transformer-BiLSTM Hybrid]] - Transformer self-attention + BiLSTM bidirectional temporal modeling for electricity price forecasting.
- [[PICNN|Partial Input Convex Neural Network (PICNN)]] - Eliminates quantile crossing by learning convex functions with respect to quantile levels.
- [[LSTM_Transformer|LSTM-Transformer Hybrid]] - Sequential LSTM + Multi-Head Self-Attention for real-time battery SOC & station demand prediction.
- [[MS_MPC|Multiscenario Stochastic MPC (MS-MPC)]] - Two-layer stochastic MPC with scenario reduction for real-time V2G microgrids.
- [[MQ_TCN|Multi-Quantile Temporal Convolutional Network (MQ-TCN)]] - Dilated causal convolution with multi-quantile regression heads.
- [[FEDM|Feature-Enhanced Deep Learning Method (FEDM)]] - Pearson correlation prior reweighting + GRN + Multi-Head Self-Attention.
- [[XGBoost|Extreme Gradient Boosting (XGBoost)]] - Gradient boosted decision tree model outperforming deep learning on tabular EV load features.
- [[EVSFD|EV Scheduling Feasible Domain (EVSFD)]] - Dynamic SOC and power boundary model for EV parking lot schedulable capacity.
- [[PAG|PAG (Physics-Informed Attention Graph)]] - Combines PIML pre-training with GAT and TPA-LSTM for causal price elasticity modeling.
- [[ResTrans|Multi-Branch ResNet-Transformer (ResTrans)]] - Multi-branch spatial ResNet + temporal 1D-CNN Transformer.
- [[MetaProbformer|MetaProbformer (Reptile + Probformer)]] - Meta-learning Informer model for few-shot probabilistic load forecasting.
- [[Deep_Gaussian_Process|Deep Gaussian Process (DGP)]] - Multi-layer non-parametric Bayesian model for data-scarce & anomalous load forecasting.
- [[GCN|Graph Convolutional Network (GCN)]] - Captures spatial topologies and road network graph dependencies.
- [[Q_Learning|Q-Learning Reinforcement Learning]] - Model-free RL for dynamic hourly forecasting model selection.
- [[Lyapunov_Optimization|Lyapunov Optimization & Virtual Queueing]] - Real-time optimal power dispatch with bounded delay guarantees.
- [[CNN|Convolutional Neural Network (CNN)]] - Extracts spatial and local receptive features from time-series and traffic flow.
- [[Ensemble_Stacking|Ensemble Stacking Learning]] - Combines multiple neural base learners using a meta-learner.
- [[Transformer|Transformer & Attention Mechanisms]] - Self-attention models for long-range temporal dependencies.
- [[LSTM|Long Short-Term Memory (LSTM)]] - Recurrent neural network for temporal sequential forecasting.
- [[GRU|Gated Recurrent Unit (GRU)]] - Efficient RNN variant with reset and update gates.

## 📐 Performance & Evaluation Metrics (`wiki/metrics/`)
- [[V2G_SVE|V2G Scheduling Value Error (V2G-SVE)]] - Value-oriented metric measuring actual V2G scheduling performance degradation ($r=0.9994$).
- [[MAE|Mean Absolute Error (MAE)]] - Measures average magnitude of errors. Loss function for deep networks.
- [[RMSE|Root Mean Squared Error (RMSE)]] - Penalizes large forecast errors quadratically; sensitive to outliers.
- [[MAPE|Mean Absolute Percentage Error (MAPE)]] - Relative percentage error; undefined at zero load.
