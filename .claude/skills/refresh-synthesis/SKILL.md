# Refresh Synthesis Skill (`/refresh-synthesis`)

This skill defines the process for updating the macro-level view of the literature and running automated Python scripts to keep the vault indexes synchronized.

---

## Key Principles & Rules

1. **UTF-8 Requirement:** All text files must be written/appended using Python with `encoding="utf-8"`.
2. **Digest Scripting:** The `paper_digest.md` file is strictly generated by `gen_paper_digest.py`. Never hand-edit it.

---

## Workflow Steps

### Step 1: Run Generation Scripts

- Execute `python gen_paper_digest.py` from the root of the vault.
- Verify that the script completes successfully and that `paper_digest.md` has been updated with the latest papers from `wiki/papers/`.
- If new papers contain novel datasets, also run `python scan_datasets.py` (if applicable) and review `dataset_extraction_report.md` for missing entries.
- **Verify index counts** — after regeneration, sanity-check:
  ```bash
  # paper count in digest header vs index.md "ALL N" vs raw_sources/*.pdf count
  grep -c "^\- \[\[" index.md
  ls raw_sources/*.pdf | wc -l
  head -5 paper_digest.md   # "papers: N"
  ```
  All three should be consistent (allow `raw_sources/*.pdf` to be slightly higher if staging files exist in `New/`).

### Step 2: Update Research Gaps & Summaries

- Read the newly generated `paper_digest.md` to identify shifting trends (e.g., a move from LSTMs to Transformers, or new federated learning applications).
- Open `research_gaps.md` and `progress_summary_and_research_gaps.md`:
  - Update paper counts.
  - Refine existing gap mappings.
  - Inject new novelty claims or contradict prior claims based on new literature.
- Open `proposed_architectures.md` and `transformer_research_ideas.md`:
  - If a new paper implements an architecture previously considered a "gap", mark the gap as "addressed by [[Paper_Name]]" and propose the next evolution.

### Step 3: Vault Logging

- Update the `last_updated` frontmatter in the synthesis files.
- Append a log entry to `log.md` summarizing the refresh:
  ```markdown
  ## [YYYY-MM-DD] synthesis-refresh | Vault Maintenance
  - Ran `gen_paper_digest.py` (papers: N) + `scan_datasets.py`.
  - Verified index counts: index.md ALL N, raw_sources/*.pdf N.
  - Updated `research_gaps.md` based on recent ingestions.
  ```
