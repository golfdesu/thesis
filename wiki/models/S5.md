# S5 (Simplified State Space Layers)

## Overview
A simplified State Space Model (SSM) architecture that utilizes multi-input multi-output (MIMO) continuous-time state spaces with parallel scans and diagonalized transition matrices.

## Literature Usage
- [[2026_FlowState_Sampling_Rate_Equivariant_Forecasting]] — FlowState utilizes an S5 SSM encoder with gating to achieve sampling-rate equivariance across continuous temporal resolutions.
