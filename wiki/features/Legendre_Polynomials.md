# Legendre Polynomials

## Overview
Orthogonal polynomials used in HiPPO state-space memory initialization and functional decoders to approximate continuous functions over bounded intervals.

## Literature Usage
- [[2026_FlowState_Sampling_Rate_Equivariant_Forecasting]] — Default orthogonal basis in FlowState's Functional Basis Decoder (FBD).
