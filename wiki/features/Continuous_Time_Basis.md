# Continuous Time Basis

## Overview
Representing time series via functional basis coefficients (e.g., Legendre polynomials, Fourier series) enabling continuous-time representation sampleable at arbitrary frequencies.

## Literature Usage
- [[2026_FlowState_Sampling_Rate_Equivariant_Forecasting]] — FlowState maps SSM latent states to continuous polynomial bases via a Functional Basis Decoder (FBD).

- [[2026_TS_ICL_Time_Indexed_Foundation_Model]] — Uses Perceiver cross-attention to embed irregular continuous timestamps into latent grid tokens.
