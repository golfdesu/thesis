# 📁 EIA-930 Hourly Electric Grid Monitor

## Overview
The U.S. Energy Information Administration's **Hourly Electric Grid Monitor** (EIA-930) publishes hourly system-level demand, forecast demand, and net generation by fuel type for the North American balancing authorities — a standardized, continuously updated source for grid-level load-forecasting benchmarks.

## Coverage Highlights
| Grid | Peak | Character |
|------|------|-----------|
| PJM | 150.4 GW | Largest US ISO |
| MISO | 127.1 GW | Wind-rich |
| ERCOT | 85.5 GW | Isolated / extreme-weather prone |
| CAISO | 47.1 GW | Duck curve |
| ISO-NE | 25.6 GW | Winter-peaking |
| NYISO | 32.1 GW | Dense urban summer peaks |
| SWPP | 54.4 GW | Added for weather experiments in Hong & Lee |
