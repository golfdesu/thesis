# Bramblemet Sensor Network

The **Bramblemet network** — four real-time coastal stations (Bramblemet on Bramble Bank, Cambermet at Chichester Bar, Chimet off Hayling Island, Sotonmet at Southampton Dock Head) run by the Solentmet Support Group with ABP Southampton hydrography. Verified 2026-08: archives report every **5 minutes**, ~10 climate signals per station (wind, air/sea temperature, pressure, tidal height; Cambermet adds wave height/period), commonly used as a 4-task multi-output regression benchmark (e.g. [[2013_Roberts_Gaussian_Processes_Time_Series]]).

The dataset entry records access conditions, temporal resolution, geographic coverage, and the forecasting studies in this knowledge base that benchmark on it. Follow the links below to those papers for per-dataset experimental settings and results.
