# 📁 DiffPLF California City EV Charging Dataset

## Overview
Public EV charging station usage dataset from California cities used to benchmark DiffPLF (Conditional Diffusion Probabilistic Forecasting). Demonstrates conditional multi-trajectory load generation under varying EV arrival rates.

## Access Links & Repositories
- **Kaggle Dataset**: [EV Charging Station Usage of California City](https://www.kaggle.com/datasets/venkatsairo4899/ev-charging-station-usage-of-california-city)
- **GitHub Repository**: [LSY-Cython/DiffPLF](https://github.com/LSY-Cython/DiffPLF)

## Key Features Provided
- Charging station occupancy and session start/end times.
- Aggregate power load curves per station.
