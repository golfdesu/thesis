EXPERIMENTS Dataset and Setup. HyKANet is implemented in PyTorch and evaluated on an Intel(R) i7-11700 CPU (2.5GHz) with an NVIDIA RTX 3090 GPU. Each experiment is repeated five times, and aver- age results are reported. The dataset is split into 70%/15%/15% for training, validation, and testing. The model is trained with Adam op- timizer (learning rate 0.001, weight decay 1e−5), batch size 64, and up to 200 epochs, using gradient clipping (max norm 5) and early stopping (patience 20) for stability. Input sequences are 12 steps (1 hour at 5-minute resolution) with prediction horizons of 3, 6, 9, and 12 steps (15–60 minutes). Core hyperparameters are: spatiotemporal feature dimension 58, external feature dimension 6, hidden dimen- sion 128; multi-scale Mamba with state dimensions [8, 16, 48] for short/medium/long-term modeling (d conv=4, expand=2); KAN with grid size 5 and spline order 3; cross-attention with dy- namic head numbers (st feat dim/16). The weather processor handles 12 meteorological variables with projection dimension 32 and outlier detection threshold 3.0. Training uses an adaptive loss (MSE/MAE/Smooth L1 with weights [0.5, 0.3, 0.2]) and regular- ization (α = 0.1, β = 0.01). Dropout rates are 0.3/0.2/0.1 for main, weather, and attention components, respectively, with GELU activation. All inputs are normalized by Z-score standardization. Table 1 reports the performance of HyKANet and multiple baselines across 15–60 minute prediction intervals, eval- uated using RMSE, MAPE, RAE, and MAE. CONCLUSION In this paper, we proposed HyKANet, a unified and lightweight framework for EV charging demand forecasting. By integrating a HydraMamba temporal-spatial backbone, an attention-based con- textual fusion module, and a KAN decoder, our model effectively captures multi-scale temporal dependencies, hierarchical spatial patterns, and the influence of external contextual factors.
