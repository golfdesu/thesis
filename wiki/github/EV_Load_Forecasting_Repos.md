# 🐙 EV Charging Load Forecasting Repositories

## Overview
This note collects official GitHub repositories, open-source code implementations, and dataset repositories specifically created for Electric Vehicle (EV) charging load demand forecasting and station management.

## Repositories & Citation Graph

### 1. DiffPLF (Conditional Diffusion Model for EV Load Forecasting)
- **Repository URL**: `https://github.com/LSY-Cython/DiffPLF`
- **Description**: Official PyTorch implementation of DiffPLF conditional denoising diffusion probabilistic model for EV charging demand.
- **Cited Paper**: [[2024_Li_DiffPLF_Conditional_Diffusion_EV]]

### 2. MetaProbformer (Few-Shot Probabilistic EV Load Forecasting)
- **Repository URL**: `https://github.com/XingshuaiHuang/MetaProbformer`
- **Description**: Meta-learning (Reptile) combined with Informer for few-shot probabilistic load forecasting at target EV stations.
- **Cited Paper**: [[2023_Huang_MetaProbformer_EV_Load]]

### 3. PAG / ST-EVCDP (Physics-Informed Attention Graph for EV Demand)
- **Repository URL**: `https://github.com/IntelligentSystemsLab/ST-EVCDP`
- **Description**: Spatio-temporal Physics-Informed Attention Graph (PAG) architecture for regional EV charging demand prediction.
- **Cited Paper**: [[2024_Qu_Physics_Informed_GAT_EV_Load]]

### 4. FEDQR Dataset & Model (Feature-Enhanced EV Load Forecasting)
- **Repository URL**: `https://github.com/Kenny4everlucky/FEDQR_dataset`
- **Description**: Open-source feature-enhanced deep learning dataset and quantile regression model code for station load forecasting.
- **Cited Paper**: [[2024_Cao_Feature_Enhanced_Probabilistic_EV_Load]]

### 5. ACN-Data & ACN-Portal (Caltech Adaptive Charging Network Framework)
- **Repository URL**: `https://github.com/zach401/acnportal`
- **Description**: Open-source Python toolkit for EV charging research, data collection, and algorithm evaluation developed at Caltech.
- **Cited Paper**: [[2026_Tang_PC_M3_Mamba_EV_Clusters]]

### 6. Hourly EV Charging Load Dataset Repo
- **Repository URL**: `https://github.com/shivkumarjadon6/Hourly_EV`
- **Description**: Open repository containing hourly public charging station consumption series and benchmark scripts.
- **Cited Paper**: [[2026_Liu_MFT_Multi_Scale_Fusion_Transformer]]

### 7. EnergyMamba / GE-Mamba (Graph-Enhanced Selective SSM for Energy Consumption) — *added in [2026-08-23] ingestion pass*
- **Repository URL**: `https://github.com/UFOdestiny/EnergyMamba`
- **Description**: Official KDD '26 implementation of GE-Mamba (GCN-conditioned bidirectional Mamba in a U-Net) with [[AS_CQR]] uncertainty calibration; evaluated on Florida CBG smart-meter, [[NYISO]], and [[CAISO]] data.
- **Cited Paper**: [[2026_Yu_EnergyMamba_Graph_Mamba_ASCQR]]
